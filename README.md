# 🏠 House Price Predictor

**Built by Sujitha | AI/ML Portfolio Project**

## 📌 About
End-to-end ML web app that predicts house prices 
using Random Forest algorithm.

## 🎯 Results
- ✅ R² Score: 0.89
- ✅ Dataset: 1,460 samples (Kaggle)
- ✅ Live Predictions via Streamlit UI

## 🛠️ Tech Stack
Python | Pandas | Scikit-learn | Random Forest | Streamlit

## 🚀 How to Run
git clone https://github.com/sujithakannan25/house-price-predictor.git
pip install -r requirements.txt
streamlit run app.py
